### 3.1 Gate 1: EN↔JA Semantic Alignment & Remediation
- **Heuristic Polysemy Trap Remediation**: Archaic and distorted matches generated by naive substring/first-match heuristics in earlier pipelines were trapped and replaced with verified JMdict headwords:
  - `you` <-> `真人` (Daoist saint / archaic) ➔ Replaced with `あなた` (`ent_seq:1000490`).
  - `i` <-> `寡人` (royal first-person pronoun) ➔ Replaced with `私` (`ent_seq:1311110`).
  - `ad` <-> `西暦` (Anno Domini calendar era) ➔ Replaced with `広告` (`ent_seq:1261540`).
  - `accident` <-> `偶然` (chance / coincidence only) ➔ Replaced with `事故` (`ent_seq:1307680`).
- **404 Canonical Replacements Applied**: Verified Japanese expressions and definitions updated with exact JMdict locator tags.
- **30 Semantic Quarantines**: Concepts where English and Japanese exhibited irreconcilable semantic divergence without suitable JMdict single-sense substitutes were placed in permanent quarantine.

### 3.2 Gate 2: Vietnamese Source-First Resolution
- **Prioritized Open Sources**: Candidate lookup prioritized verified lexical datasets (`vn_word_frequencies.tsv` and `Unihan`).
- **Sino-Vietnamese Cognates (358 accepted)**: Verified genuine cognates (e.g. `chính xác` for accurate, `mạo hiểm` for adventure, `ý chí` for will, `hoàn toàn` for complete, `ngược đãi` for abuse).
- **False Cognate Traps**: Proactive quarantine prevented deceptive phonetic loans:
  - `世界` ➔ Quarantined for `circle` (prevented false translation `thế giới`).
  - `実物` ➔ Quarantined against `thực vật` (flora).
  - `交通` ➔ Quarantined against `giao thông` when context required `communication`.

### 3.3 Gate 3: AI Candidate Generation with Immutable Provenance
- Triggered strictly for source gaps (354 invocations).
- Each candidate generated with POS enforcement, CEFR-appropriate register, natural learner definition, and verified synonyms.
- **Zero-Trust Provenance**: Permanently stamped `provenance_type = "AI_GENERATED"`, embedding model ID (`gemini-2.5-flash`), input hash, prompt version, and timestamp.

### 3.4 Gate 4: Independent Blind Linguistic Judge
- Blind multi-dimensional evaluation: Semantic Equivalence, Vietnamese Naturalness, Register Match, and Confidence.
- **Auto-Accept Gate**: Required `decision == ACCEPT`, `semantic_alignment in (EXACT, GOOD)`, `naturalness == NATURAL`, and `confidence == HIGH`.
- **Outcome**: 645 concepts auto-accepted for canonical integration; 147 routed to `review_queue.json`; 242 suboptimal candidates rejected into `rejected_candidates.json`.
